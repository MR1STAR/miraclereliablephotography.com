# Miracle Reliable Photography (MR)

A responsive, dynamic one-page photography website for Lusaka, Zambia and surrounding areas.

## Files
- `index.html` — main website
- `styles.css` — responsive design and styling
- `script.js` — services, animations, gallery modal, navigation and settings
- `assets/background.jpg` — supplied photography image used as the background
